# 진실한숲교회 재정관리 시스템

교회 재정을 체계적으로 관리하는 웹 앱입니다.

## 기능
- 수입/지출 입력 (통장 구분, 성도명 관리)
- 통장 간 이체 기록
- 출납부, 월간/연간 보고서 (엑셀 + 인쇄용)
- 기부금영수증 발급 (법정 양식)
- 예산안 작성 (자동 추천)
- 데이터 백업/복원

## 설치 (GitHub Pages)
1. 이 저장소를 Fork하거나 새 저장소를 만들어 파일을 업로드합니다
2. Settings > Pages > Source: main branch 선택
3. 생성된 URL로 접속합니다

## 스마트폰 앱으로 설치
- **iPhone**: Safari에서 접속 → 공유 버튼 → "홈 화면에 추가"
- **Android**: Chrome에서 접속 → 메뉴 → "홈 화면에 추가"
